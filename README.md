# 🏖️ ByteBank

## 🚀 Tecnologias

- Next.js  
- TypeScript  
- React  
- Jest  
- StoryBook  
- Testing Library  
- Node.js 18+

---

## 📌 Funcionalidades

- Home  
- Listagem de Transações  
- Adicionar Nova Transação 
- Editar Transação 

---

## ⚙️ Pré-requisitos

Antes de começar, você precisa ter instalado:

- Node.js (versão 18 ou superior)
- npm ou yarn

Verifique:

```bash
node -v
npm -v
```

Para instalar as dependência rode:

```bash
npm install
```

Para rodar o projeto localmente:

```bash
npm run dev
```
